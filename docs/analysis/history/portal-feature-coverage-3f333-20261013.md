## Architecture and implemented behavior

Retained jobs bind the original arguments hash, workspace, target, operation IDs and deadline. Original service approvals remain explicit. Unknown outcomes cannot be replayed, and read-only recovery remains available. Credentials, code bodies, pairing codes, raw arguments and complete result bodies are not persisted in activity/history.

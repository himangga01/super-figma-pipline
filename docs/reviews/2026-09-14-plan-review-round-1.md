## Main-agent qualifications and unresolved prerequisites

- Successful tests are baseline evidence, not proof that a silently untested path is correct. New regression cases are required after planning is finalized.
- Native working copies remain same-account execution. No finding is resolved by calling them sandboxes or weakening source, timeout or visual checks.
- Arbitrary-language full semantic inference and unspecified production services are not promised. A bounded supported analyzer must expose unresolved evidence and cannot downgrade an operational case into C4.
- Windows/Node/SQLite end-to-end services can be implemented without production credentials. A missing actual Desktop session or unavailable non-Windows host is an explicit live-validation prerequisite, not a successful test.
- The complete source/closure correction is a prerequisite to running newly generated operational profiles. Capture diagnosis can proceed independently; a browser problem must not stall all shared contract work.
- The user authorized Superpowers only after final plan approval by the main agent following round 2, and authorized commit/push only after all work and final code reviews/verification. No skills, code changes, commits or pushes occurred in this planning round.

## Final judgment

Both requested planning review rounds are complete. The main agent accepts the concrete corrections and freezes final v1 after inserting the binding rules and regression scenarios into the implementation plan. No critical finding is dismissed on the basis of old passing tests. Exact algorithm and file decomposition choices remain implementation work; semantic ambiguity, identity cycles and authority gaps do not.

The supported completion target is Windows native execution with the supplied live Figma C4 artifact, both frontend presets, complete representative C2/C3 journeys and documented conditional upstream capabilities. Unknown production providers, absent live Desktop sessions and unavailable non-Windows hosts require honest named prerequisites, not fabricated verification. Such prerequisites cannot excuse a supported-path code defect or an unimplemented adapter.

Implementation may now begin under the user's explicit Superpowers authorization after the latest-version check. Two critical code-review rounds, main-agent verification/fixes, current-source final verification and final task-scoped commit/non-force push remain mandatory. No commit or push is authorized before those completion gates.
